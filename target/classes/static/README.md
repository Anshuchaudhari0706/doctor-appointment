# MediCare Frontend

This is a responsive, premium-designed frontend for the Doctor Appointment System.

## How to Run
Since this is a static frontend using Vanilla HTML/CSS/JS (due to missing Node.js environment), you can simply:

1.  Open the `frontend` folder.
2.  Double-click **`index.html`** to open it in your web browser.

## Features
- **Authentication**: Login and Registration pages with role selection (Patient, Doctor, Admin).
- **Patient Dashboard**:
    - **Dashboard**: Overview of upcoming appointments and stats.
    - **Profile**: View and manage user details.
    - **Medical Reports**: View and download medical history (mocked).
    - **My Bookings**: Manage current and past appointments.
    - **Book Appointment**: Interface to schedule new visits.
    - **Calendar**: Visual doctor availability checker.
    - **Payments**: Manage payment methods and billing history.
    - **Support**: Chat interface for help.
    - **Settings**: Toggle notifications and preferences.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom "Glassmorphism" design, fully responsive, dark/light theme aware styling.
- **JavaScript**: Single Page Application (SPA) logic handling routing and state without page reloads.
- **FontAwesome**: For icons.
- **Google Fonts**: 'Outfit' typeface.
